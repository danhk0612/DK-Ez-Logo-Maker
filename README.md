# DK Ez Logo Maker

**DK Ez Logo Maker**는 텍스트와 이미지를 조합해 간단한 로고·배너·아이콘용 PNG를 빠르게 만드는 Windows 프로그램입니다.

복잡한 그래픽 편집기 없이 캔버스 크기, 배경, 글자, 이미지를 조정하고 결과를 바로 PNG로 저장할 수 있습니다. 작업 중인 내용은 `.dklm` 프로젝트 파일로 저장해 나중에 다시 편집할 수 있습니다.

## 다운로드

GitHub의 **Releases**에서 최신 `DK-Ez-Logo-Maker-v1.0.0-win-x64.zip`을 내려받아 원하는 폴더에 압축을 풀고 `DK Ez Logo Maker.exe`를 실행합니다.

### 실행 환경

- Windows 10 / 11 64-bit
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0) 설치 필요
- 별도 설치 과정 없음

> 이 프로그램은 .NET 10이 설치된 PC를 대상으로 하는 경량 배포본입니다.

## 주요 기능

### 캔버스와 배경

- 출력 가로·세로 크기 직접 지정
- 투명 배경
- 단색 배경
- 4방향 선형 그라디에이션

### 글자 편집

- Windows에 설치된 폰트 선택
- 글자 크기, 굵기, 자간, 색상 변경
- 마우스로 위치 이동 및 크기 조절
- 가로: 왼쪽 / 중앙 / 오른쪽 정렬
- 세로: 위 / 중앙 / 아래 정렬
- 우클릭 메뉴에서 굵기·간격·정렬 빠른 변경

### 이미지 편집

- 이미지 불러오기
- 마우스로 위치 이동 및 크기 조절
- 네 모서리와 상·하·좌·우 테두리에서 크기 조절
- 가로·세로 크기 독립 조절
- 원본 비율 유지 On / Off
- 가로·세로 정렬
- 우클릭 메뉴에서 비율 유지·정렬 빠른 변경

### 미리보기

- 확대 / 축소
- 화면에 맞춤
- 원본 크기 1:1
- 이동·가로·세로·대각선 크기 조절 상태에 맞는 마우스 커서
- 글자와 이미지가 캔버스 밖으로 사라지지 않도록 위치·크기 제한

### PNG 내보내기

내보낼 때 출력 배율과 스케일링 방식을 선택할 수 있습니다.

- 출력 배율: 25% / 50% / 100% / 200% / 400%
- 스케일링: 고품질 / 일반 / 픽셀 보존
- 투명 배경 PNG 지원

### 작업 저장

작업은 `.dklm` 파일로 저장됩니다.

- 캔버스와 배경 설정
- 글자 설정 및 위치
- 이미지 설정 및 위치
- 사용 중인 이미지 데이터

이미지도 프로젝트 안에 함께 저장되므로 원본 이미지 파일을 옮기거나 다른 PC에서 프로젝트를 열어도 작업을 이어갈 수 있습니다.

## 기본 사용 방법

1. 캔버스의 가로·세로 크기를 정합니다.
2. 투명, 단색 또는 그라디에이션 배경을 선택합니다.
3. 글자를 입력하거나 이미지를 불러옵니다.
4. 미리보기에서 요소를 드래그해 위치와 크기를 조정합니다.
5. 필요하면 정렬 기능이나 우클릭 빠른 메뉴를 사용합니다.
6. 작업을 계속 보관하려면 `.dklm`으로 저장합니다.
7. 완성된 결과는 **PNG로 내보내기**를 사용합니다.

## 단축키

| 기능 | 단축키 |
| --- | --- |
| 새 작업 | `Ctrl + N` |
| 프로젝트 열기 | `Ctrl + O` |
| 프로젝트 저장 | `Ctrl + S` |
| PNG 내보내기 | `Ctrl + E` |

## 설정 저장 위치

창 크기와 위치, 최근 사용 설정, 내보내기 설정 등은 다음 위치에 자동 저장됩니다.

```text
%LOCALAPPDATA%\DK Ez Logo Maker\settings.json
```

## 개발자용 빌드

필요 환경:

- .NET 10 SDK
- Windows

```powershell
dotnet restore
dotnet run
```

배포용 빌드는 다음 스크립트를 사용할 수 있습니다.

```powershell
.\build-release.cmd
```

출력 위치:

```text
publish\win-x64
```
